# Fanbox Updater

FANBOX·Patreon에서 팔로우/후원 중인 작가의 게시물을 원하는 폴더(로컬 디스크·NAS 등 아무 경로)에 자동으로 최신화하는 Windows 프로그램입니다.

## 설치

[Releases](https://github.com/TTOGEARII/Fanbox_Downloader/releases/latest)에서 **FanboxUpdater-win-Setup.exe**를 받아 실행하면 설치됩니다.

- 새 버전이 나오면 **앱이 자동으로 감지**해서(시작 시 + 6시간마다) 상단에 "⬆ 업데이트" 버튼이 나타납니다. 클릭 한 번으로 업데이트 후 재시작됩니다.
- 설정과 받은 기록은 `%AppData%\FanboxUpdater`에 저장되어 업데이트해도 유지됩니다.

### 제거

설정 탭 맨 아래 **[프로그램 제거]** 버튼을 누르면 됩니다 (설정/기록까지 함께 지울지 선택 가능).
Windows 설정 → 앱 → 설치된 앱 → **Fanbox Updater** → 제거로도 가능합니다.

- 받아둔 파일과 저장 폴더는 건드리지 않습니다.
- 설정/기록은 `%AppData%\FanboxUpdater`에 남아 재설치 시 그대로 이어집니다. 완전히 지우려면 이 폴더도 삭제하세요.

## 처음 시작하기

작가 탭 위에 뜨는 **안내 배너**가 다음 할 일을 알려줍니다. 사이트(FANBOX / Patreon)마다 아래 순서를 한 번씩 하면 됩니다. 한 사이트만 써도 됩니다.

1. **쿠키 입력** — 설정 탭 → 사이트별 설정에서 사이트를 고르고 계정 칸에 쿠키 값을 넣은 뒤 [연결 확인]을 누릅니다.
   - FANBOX: 브라우저에서 fanbox.cc 로그인 → F12 → Application → Cookies → fanbox.cc → `FANBOXSESSID` 값
   - Patreon: 브라우저에서 patreon.com 로그인 → F12 → Application → Cookies → patreon.com → `session_id` 값
2. **저장 폴더 지정** — 설정 탭 → 저장 분류에서 게시물을 받을 폴더를 고릅니다. 그 폴더 바로 아래 하위 폴더가 작가 폴더가 됩니다.
3. **작가 매칭** — 상단 [작가 목록 새로고침]을 누르면 폴더와 작가를 자동으로 짝지어 줍니다. 안 된 폴더(주황)는 [선택]으로 직접 고릅니다.
4. **▶ 지금 최신화** — 지금 보고 있는 사이트에서 동기화가 켜진 작가의 새 게시물을 받습니다.

## 사용법

### 상단 버튼
- **▶ 지금 최신화** (F5) — 작가 탭에서 보고 있는 사이트의 새 게시물만 받습니다. 다른 사이트는 받지 않습니다. **■ 중지** (Esc)로 멈출 수 있습니다.
- **작가 목록 새로고침** (Ctrl+R) — 로그인된 모든 사이트의 팔로우/후원 작가 목록을 다시 가져와 자동 매칭합니다.
- **선택 작가 다시 받기** — 작가 탭에서 고른 작가의 게시물을 지정 날짜(1개월·3개월·1년·전체) 이후로 받은 기록과 무관하게 다시 받습니다. 플랜을 올려 예전 글이 열람 가능해졌을 때나 압축 해제 옵션을 나중에 켰을 때 쓰세요 (이미 있는 파일은 건너뜁니다).
- 창을 닫으면 트레이로 들어가며, 스케줄이 켜져 있으면 백그라운드에서 자동 실행됩니다. 완전 종료: 트레이 아이콘 우클릭 → 종료.

### 작가 탭
- 왼쪽 위 **FANBOX / Patreon 버튼**으로 사이트를 전환합니다. 폴더·작가·분류·매칭은 사이트별로 완전히 분리되어 있습니다.
- 상단 요약(폴더 수 · 매핑 · 미매핑 · 동기화 대상), 검색창(폴더명·작가명·ID), 분류 필터.
- 저장 폴더 ↔ 작가가 자동 매칭됩니다. 매핑 여부가 ✔/! 아이콘과 행 색으로 표시되고, 매핑된 작가가 위로 정렬됩니다.
- 매칭 안 된 폴더는 **[선택] 버튼**으로 작가 목록에서 고르거나(검색 가능, 더블클릭으로 바로 매핑), creatorId 칸에 직접 입력합니다.
  - FANBOX: 작가 주소 `https://xxxx.fanbox.cc`의 `xxxx`
  - Patreon: 작가 주소 `https://www.patreon.com/이름`의 `이름` (앞에 `patreon:`이 자동으로 붙습니다)
- **분류** 드롭다운 — 분류에 따라 저장 루트가 달라집니다. 바꾸면 기존 폴더 이동도 물어봅니다.
- **일러 기준(장)** — 이 작가만의 일러스트 분리 기준 장수. 빈칸이면 사이트 설정값, 0이면 분리 안 함.
- 행 **더블클릭 → 폴더 열기**, 우클릭 → 폴더 열기 / 작가 페이지 열기 / 작가 매핑 변경 / 이 작가 다시 받기.
- **동기화** 체크를 끄면 그 작가는 제외됩니다. 기본값은 매핑된 작가만 켜짐.
- 같은 작가를 두 사이트에서 받으려면 각 사이트의 분류에 폴더를 따로 두면 됩니다 (예: `…\영상\fanbox\작가`, `…\영상\patreon\작가`).

### 설정 탭
모든 설정은 **바꾸는 즉시 자동 저장·반영**됩니다 (글자 입력칸은 다른 곳을 클릭하면 반영). 위쪽은 사이트별 설정, 아래쪽은 공통 설정입니다.

**사이트별 설정** — FANBOX / Patreon 버튼으로 전환하며, 선택한 사이트에만 적용됩니다.
- **계정**: 로그인 쿠키(표시/숨김 토글)와 [연결 확인]. 만료되면("인증 실패") 다시 넣어주세요. 비워 두면 그 사이트는 쓰지 않습니다.
- **저장 분류**: 분류(이름 + 저장 루트 경로)를 원하는 만큼 추가/삭제합니다. 각 루트 바로 아래 하위 폴더가 작가 폴더로 매칭되어 작가 탭에 바로 나타납니다. 첫 번째 분류가 기본값입니다.
- **일러스트 분리**: '일러 분리'를 체크한 분류의 낱장 일러스트(이미지 N장 이하, 영상·압축 없음)는 별도 일러스트 저장 경로로 저장됩니다.
- **유료 / 무료 게시물 받기**: 유료(FANBOX 플랜 구독 / Patreon 후원자 전용)와 무료(공개) 게시물을 각각 받을지 체크합니다 (기본: 유료만).
  Patreon은 게시물에 실제로 첨부된 이미지·영상·첨부파일만 받고, 미리보기(티저·썸네일) 이미지는 받지 않습니다. Patreon 자체 스트리밍 영상은 직접 받을 수 없어 글 파일에 링크로 남깁니다.
- **게시물 폴더 없이 작가 폴더에 바로 저장**: 켜면 게시물마다 폴더를 만들지 않고 작가 폴더에 파일을 바로 저장합니다. 파일명 규칙은 `{title}_{index}`(제목_01.jpg, 제목_02.jpg …)가 기본이고, `{id}_{index}`(게시물번호_01.jpg)처럼 바꿀 수 있습니다 (`{title}` `{index}` `{id}` `{date}` `{creator}` 사용 가능, 확장자 자동). 글 내용은 폴더 이름 규칙으로 지은 `.txt`로 저장됩니다.
  하위의 **일러스트(분리 저장) 게시물만 적용**을 켜면 일러스트 경로로 가는 낱장 일러만 이렇게 저장하고, 나머지 게시물은 평소처럼 게시물 폴더로 저장합니다.
- 글 내용 저장(post.txt) · 표지 이미지 저장 · 폴더 없는 팔로우 작가도 자동 생성
- **외부 링크 자동 다운로드**: 본문에 걸린 Dropbox · Google Drive · 직접 링크를 자동으로 받습니다. 미지원 호스트(MEGA 등)는 post.txt에 링크로 남깁니다.
- **압축파일 자동 해제**: 받은 zip을 게시물 폴더 안에 압축파일명과 같은 폴더로 풉니다 (일본어 파일명 지원, RAR·7z 미지원). 해제 후 원본 zip 삭제 옵션도 있습니다.
- **받을 파일 종류**: 이미지 / 영상 / 압축파일 / 기타

**공통 설정** — 모든 사이트에 적용됩니다.
- 게시물 폴더 이름 규칙(`{date} {title}` 기본 — `{id}`, `{creator}`도 사용 가능), 날짜 형식, 동시 다운로드 수(1~8)
- **자동 실행 스케줄**: 매일 / 매주(요일) / 매월(날짜) 지정 시각, 또는 N시간 간격. 프로그램이 트레이에 있을 때 로그인된 모든 사이트를 돌립니다. 매월 31일처럼 그 달에 없는 날은 말일에 실행됩니다.
- 시작 시 트레이로 최소화 · 닫기 버튼 → 트레이로 이동
- [데이터 폴더 열기]로 설정·기록·로그 파일 위치를 바로 열 수 있습니다.

### 로그 탭
동기화 진행 기록입니다. 자동 스크롤 끄기, 화면 지우기, 로그 파일 열기 버튼이 있습니다.

### 명령줄
```
FanboxUpdater.exe --sync     ← 창 없이 1회 동기화 후 종료 (Windows 작업 스케줄러 연동용, 로그는 app.log)
```

## 알아두면 좋은 점

- 이미 받은 게시물은 기록(`state.json`) 기준으로 건너뜁니다. 저장 폴더에서 파일을 지워도 다시 받지 않으니, 다시 받으려면 "선택 작가 다시 받기"를 쓰세요.
- 작가별 게시물은 최신 페이지부터 확인하고, 지난 동기화를 끝까지 마친 작가는 새 글이 없으면 더 오래된 페이지를 조회하지 않아 작가가 많아도 빠릅니다.
- 쿠키는 사이트에 로그인한 브라우저 세션 값이므로 다른 사람과 공유하지 마세요. 로그아웃하거나 만료되면 다시 넣어야 합니다.
- 압축 해제·외부 링크 같은 다운로드 옵션은 **사이트별**이라, 한 사이트에서 켠 값이 다른 사이트에는 적용되지 않습니다.

## 데이터 파일 (`%AppData%\FanboxUpdater`)

| 파일 | 설명 |
|---|---|
| `settings.json` | 모든 설정 (쿠키, 경로, 매핑, 분류, 스케줄) |
| `state.json` | 받은 게시물 기록. **지우면 전부 다시 받으므로 주의** |
| `app.log` | 동기화 로그 |
